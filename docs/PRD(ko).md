# 영어 말하기 연습 앱(가칭) PRD

## 1. What — 한 줄 정의
영어 말하기 연습 앱은 문장을 폴더별로 모아 놓고, 듣기(TTS) → 가리기 → 말하기(STT) → 숙련도 기록 순서로 반복 연습하게 해주는 웹앱을, 영어 스크립트로 공부하는 한국어 화자 학습자에게 제공합니다.

## 2. 메인 사용 시나리오 (3개)
1. 사용자가 연습할 문장을 준비할 때, 폴더를 만들고 CSV를 올리거나 문장을 한 개씩 직접 입력해서 그 폴더에 추가한다.
2. 사용자가 문장을 연습할 때, 영어 발음을 듣고(TTS) 영어를 가린 채 한국어를 보며 영어로 말한다(STT). 인식된 결과를 눈으로 원문과 비교하고, 숙련도를 정한 뒤 다음 문장으로 넘어간다.
3. 사용자가 복습할 때, 폴더 안에서 숙련도 필터(예: 완전 생소)로 문장을 좁혀 그 목록 안에서만 연습한다.

## 3. Who — 타겟 사용자
- 페르소나: 영어 오디오/스크립트로 공부하며, 읽는 데 그치지 않고 직접 말해 보려는 한국어 화자 학습자. 문장 자료는 앱 밖에서 이미 문장 단위로 준비해 둔다.
- 핵심 페인 포인트: 스크립트를 눈으로 읽으면 "말할 수 있는지"를 확인하기 어렵다. 문장 단위로 가려 가며 말하고 결과를 바로 확인하는 연습 도구가 없다.
- 성공 정의: 문장의 숙련도가 "완전 생소"에서 "획득"으로 옮겨 가는 것이 눈에 보이고, 폴더 단위로 연습을 이어갈 수 있다.

## 4. Behavior — 화면별 명세

화면 구성: 앱은 "메인 화면(연습)"에서 시작한다. 폴더 패널과 문장 추가 패널은 메인 화면 위에서 열리고, 메인 화면의 버튼으로 "문장 표 화면"에 이동한다.
역할 분리: 메인 화면 = 한 문장에 집중해서 연습하는 곳, 문장 표 화면 = 모은 문장을 한눈에 보고 관리하는 곳.

### 메인 화면 — 연습 (URL: /folders/:folderId)
**진입 조건**: 앱을 열면 처음 보이는 화면. 폴더가 있으면 가장 먼저 만든 폴더를 자동 선택하고 첫 문장에서 시작한다. 폴더가 없으면 폴더 패널을 열어 폴더 만들기를 안내한다.

**UI 요소**:
- 상단 바:
  - 현재 폴더 이름 버튼 → 폴더 패널 열기
  - [문장 표 보기] 버튼 → 문장 표 화면
- 좌측: + 버튼 → 문장 추가 패널 열기
- 열 헤더 (번호 / 영어 / 한국어 / 내가 말한 내용 / 숙련도):
  - 영어 열 헤더에 보임·숨김 토글, 한국어 열 헤더에 보임·숨김 토글 (각각 독립)
  - 숙련도 열 헤더에 필터 체크박스 3개 (완전 생소 / 활용 미숙 / 획득). 기본은 셋 다 체크 = 전체
  - 숨김은 내용만 가리고 열 자리는 유지해서 레이아웃이 흔들리지 않게 한다
- 본문 (다이얼식 표):
  - 중앙 행 = 현재 문장. 카드 형태, 굵은 글씨, 테두리로 강조
  - 중앙 행과 바로 위·아래 행, 총 3개 행은 완전한 형태(모든 열 표시). 위·아래 행은 중앙보다 덜 강조
  - 그 바깥의 앞뒤 행은 다이얼처럼 작고 흐리게. 멀어질수록 scale과 opacity가 줄어든다. 위아래 각 1~2개 정도
  - 필터가 켜져 있으면 해당 숙련도의 문장만 나타나고, 번호는 폴더 안 원래 번호를 유지한다
  - 중앙이 아닌 행을 클릭하면 그 행이 중앙으로 이동한다
- 우측: [위로] [아래로] 버튼 (= 이전 / 다음). 마우스 휠로도 이동. 회전형 스크롤바 모양은 v1에서 제외
- 중앙 행의 셀에서만 동작하는 것들 (나머지 행은 읽기와 클릭 이동만 가능):
  - 영어 셀: [듣기] 버튼 (브라우저 내장 TTS). 영어 열이 가려져 있어도 사용 가능
  - 내가 말한 내용 셀: 마이크 버튼 + 텍스트 입력창
  - 숙련도 셀: 숙련도 배지

**사용자 액션**:
- [듣기] 클릭 → 영어 문장을 음성으로 재생
- 마이크 클릭 → 녹음 시작, 버튼이 녹음 중 상태로 바뀐다. 말한 내용이 입력창에 실시간으로 표시된다. 실시간 표시가 내장 STT에서 가능한지는 Plan이 확인하고, 불가하면 인식이 끝난 뒤 표시한다. 다시 클릭하면 녹음 중지
- 입력창에 직접 타이핑 가능
- 입력창의 내용 = 그 문장의 최근 발화(last_transcript). 최근 1개만 저장하고 새로 말하면 덮어쓴다. 저장 시점은 인식 종료 시, 또는 타이핑 후 입력창을 벗어날 때
- 원문과의 비교 표시는 없다. 사용자가 눈으로 비교
- 숙련도 배지 클릭 → 완전 생소 → 활용 미숙 → 획득 → 완전 생소 순으로 바뀌고 즉시 저장
- [위로]/[아래로] → 이웃 행이 중앙으로 이동. 규칙: 현재 번호보다 작은(위) / 큰(아래) 번호 중, 지금 필터를 통과하는 가장 가까운 문장
- 영어/한국어 열 토글 → 해당 열을 가림·보임. 문장을 이동해도 상태 유지. 처음 진입 시 기본값은 둘 다 보임, 새로고침 후에는 저장하지 않음
- 필터 체크박스 변경 → 다이얼 즉시 갱신. 현재 중앙 행이 필터에서 빠지면 가장 가까운 통과 문장으로 이동

**예외 처리**:
- 폴더가 하나도 없음 → 다이얼 대신 "폴더를 만들어 주세요" 표시, 폴더 패널 열기 버튼 제공
- 폴더에 문장이 없음 → "문장이 없습니다. + 버튼으로 추가하세요" 표시
- 필터 결과가 0개 → "조건에 맞는 문장이 없습니다" 표시
- 숙련도를 바꿔서 현재 문장이 필터에서 빠지는 경우 → 이동하기 전까지는 중앙에 그대로 두고, [위로]/[아래로]를 누르면 위 이동 규칙을 적용
- 다이얼식 원래 적용: 첫 문장에서 [위로] 누르면 마지막 문장으로, 마지막 문장에서는 [아래로] 누르면 첫 문장으로
- STT 미지원 브라우저 → 마이크 버튼 비활성 + 안내. 직접 타이핑은 계속 가능. Chrome 및 최신 브라우저 기준 (브라우저 내장 기능만 사용)
- 마이크 권한 거부 → 안내 문구
- 인식 결과가 없거나 실패 → 안내 문구. 기존 발화는 덮어쓰지 않음
- TTS 미지원 또는 재생 실패 → 안내 문구
- en이 비어 있는 문장 → [듣기] 비활성. en 또는 ko가 빈 셀은 "(없음)" 표시

**다음 화면**: 문장 표 화면 ([문장 표 보기])

### 폴더 패널 — 메인 화면에서 열림
**진입 조건**: 메인 상단의 폴더 이름 버튼을 눌렀을 때. 폴더가 없을 때는 자동으로 열림.
**UI 요소**:
- 메인 화면 위에 열리는 패널 (옆에서 슬라이드 또는 오버레이 형태로 열림)
- 새 폴더 이름 입력창 + [만들기] 버튼
- 폴더 목록: 각 항목에 이름, 문장 수, [삭제] 버튼
- 닫기 버튼
**사용자 액션**:
- 폴더 클릭 → 그 폴더가 현재 폴더가 되고 패널이 닫힌다. 메인은 그 폴더의 첫 문장에서 시작
- 만들기 → 이름 앞뒤 공백을 제거하고 목록에 추가
- 삭제 → 확인창 표시 후 폴더와 그 안의 모든 문장을 함께 삭제. 삭제한 폴더가 현재 폴더였다면 남은 폴더 중 가장 먼저 만든 폴더로 전환하고, 없으면 빈 상태
**예외 처리**:
- 이름이 비어 있음 → 만들지 않고 안내
- 이미 있는 이름 → 만들지 않고 "이미 있는 폴더 이름"이라고 안내
**다음 화면**: 메인 화면 (패널 닫힘)

### 문장 추가 패널 — 메인 화면과 문장 표 화면에서 공용으로 열림
**진입 조건**: 메인의 + 버튼. 문장 표 화면에도 같은 버튼을 둔다.
**UI 요소** (작은 패널 또는 모달):
- 추가 방식 선택: "파일로 추가" / "직접 입력"
- 공통: "추가할 폴더" 선택. 기본값은 현재 폴더
- 파일로 추가: CSV 파일 선택 버튼, 형식 안내 문구 ("UTF-8로 저장한 CSV를 올려주세요")
- 직접 입력: 영어 원문 입력창, 한국어 직역 입력창, [추가] 버튼
**사용자 액션**:
- 직접 입력 → 선택한 폴더의 맨 뒤 번호로 문장 추가. en과 ko는 둘 중 하나만 있어도 됨
- CSV 업로드 → 선택한 폴더의 맨 뒤에 이어 붙임. 같은 영어 문장이 있어도 중복 허용
- CSV 형식: 열은 id, en, ko, transcript, 첫 행은 header. id 열 값은 무시하고 행 순서대로 번호를 부여. transcript 열은 그 문장의 최근 발화(last_transcript)로 저장. 문장 안의 쉼표(따옴표로 감싼 값)와 한글이 깨지지 않게 처리, 인코딩은 UTF-8 기준
- 엑셀(.xlsx) 직접 업로드는 v1에서 제외하고 CSV만 받는다. 엑셀 사용자는 CSV로 저장해서 올린다
- 추가 완료 → 결과 요약 표시 (예: "○○ 폴더에 12개 추가, 2개 건너뜀"). 열려 있던 화면은 즉시 갱신
**예외 처리**:
- en과 ko가 둘 다 비어 있음 → 추가 불가, 안내
- CSV에서 en/ko가 둘 다 빈 행 → 그 행만 건너뜀
- CSV 형식 오류(필수 열 없음, 빈 파일, CSV가 아닌 파일) → 업로드 전체 취소, 안내
**다음 화면**: 열려 있던 화면 (패널 닫힘)

### 문장 표 화면 (URL: /folders/:folderId/table)
**진입 조건**: 메인 화면의 [문장 표 보기]를 눌렀을 때. 현재 폴더의 문장을 보여준다.
**UI 요소**:
- 상단: 폴더 이름, [메인으로 돌아가기] 버튼, + 버튼 (문장 추가 패널)
- 필터: 숙련도 체크박스 3개. 메인 화면과 같은 필터 상태를 공유한다
- 정렬: 번호순(기본) / 숙련도순. 이 화면의 표에만 적용하고, 메인 다이얼은 항상 번호 순
- 표: 폴더 안 문장을 한눈에 보는 완전한 형태
  - 열: 번호 / 영어 / 한국어 / 내가 말한 내용(최근 발화) / 숙련도 / [수정] [삭제]
  - 내가 말한 내용과 숙련도는 읽기 전용으로 표시
  - 길면 표 안에서 스크롤, 헤더 고정
- 발화 기능은 이 화면에서 사용할 수 없다: 마이크, STT, 발화 입력창 없음. TTS([듣기])도 이 화면에는 두지 않는다
**사용자 액션**:
- 필터/정렬 변경 → 표 즉시 갱신
- 행 클릭 → 메인 화면으로 이동하고 그 문장이 중앙에 온다
- [수정] → 그 행의 영어/한국어를 입력창으로 바꿔 편집하고 [저장]/[취소]. 수정해도 숙련도와 발화는 유지
- [삭제] → 확인창 후 그 문장과 발화 기록을 함께 삭제. 뒤 문장의 번호가 하나씩 당겨진다
- [메인으로 돌아가기] → 메인 화면. 이전 중앙 문장 위치를 유지
**예외 처리**:
- 폴더에 문장이 없음 → "문장이 없습니다. + 버튼으로 추가하세요" 표시
- 필터 결과가 0개 → "조건에 맞는 문장이 없습니다" 표시
- 수정 시 en과 ko가 둘 다 비어 있음 → 저장 불가, 안내
**다음 화면**: 메인 화면

## 5. Data Model
저장 위치: 브라우저 안(서버·계정 없음). 저장 방식: localStorage. 폴더·문장 전체를 한 키(JSON)로 저장하여 약 5MB 용량으로 수천 문장 지원.

folders
- id: 고유 식별자, 생성 후 변하지 않음
- name: 문자열, 필수, 폴더 간 중복 불가

sentences
- folder_id: folders.id를 참조, 필수. 폴더를 삭제하면 그 안의 문장도 함께 삭제
- id: 문장 행의 고유 식별자. 생성 후 변하지 않음. 화면에는 보이지 않고, 문장을 구분하는 용도(React key, "현재 문장" 상태, 수정·삭제 대상 지정)로만 사용
- position: 정수, 폴더 안에서 몇 번째 문장인지를 나타내는 번호. 1부터 시작하고 빈틈 없이 이어짐(1..N). 새 문장은 맨 뒤 번호를 받음. 화면의 "번호" 열에는 이 값이 표시됨. 문장을 삭제하면 뒤 문장의 position이 하나씩 줄어듦
- en: 문자열, 비어 있어도 됨
- ko: 문자열, 비어 있어도 됨
- (제약) en과 ko 중 하나는 공백 제외 비어 있지 않아야 함
- (제약) en은 중복 허용
- proficiency: 정수 0 / 1 / 2 = 완전 생소 / 활용 미숙 / 획득. 기본값 0. 필터와 정렬에 사용. 화면에는 한국어 라벨로 표시
- last_transcript: 문자열, 비어 있어도 됨. 그 문장의 최근 발화 1개만 저장하고 새로 말하면 덮어씀. 문장을 지우면 함께 사라짐

관계: folders 1 : N sentences

저장하지 않는 것(조회 시 계산): 화면의 필터/정렬 결과, 다음/이전 이동 대상, 가리기/보이기 상태(UI 상태)

구현 시 주의 (Plan에서 검토):
- position이 "몇 번째"이므로 문장을 삭제하면 뒤 문장의 position을 하나씩 줄여야 함. 이 갱신은 전부 성공하거나 전부 취소되는 방식으로 처리할 것
- id는 변하지 않으므로, 화면 목록의 React key와 "현재 문장" 상태는 position이 아니라 id로 잡을 것. position은 삭제 뒤 바뀌므로 key나 "현재 문장" 식별에 쓰지 말 것
- CSV의 id 열은 여전히 무시함. 새 문장의 id는 앱이 부여하고, position은 폴더 맨 뒤부터 행 순서대로 부여
- 브라우저 저장소는 사용자가 사이트 데이터를 지우면 함께 사라짐. 문장 수가 많아졌을 때의 용량 한계도 확인할 것

## 6. Out of Scope — 이번 버전에 만들지 말 것
- ❌ 계정/로그인, 서버, DB: v2. v1은 브라우저 저장소만 사용
- ❌ 발음 점수화, 원문과의 자동 비교 표시(단어 단위 일치/불일치 등): 비교는 사용자가 눈으로 함
- ❌ 오디오 → 텍스트 변환, 문장 분리: 앱 밖에서 끝낸 문장만 입력으로 받음
- ❌ 오디오 재생 동기화, 모바일 앱: v2
- ❌ 폴더 이름 변경, 문장을 다른 폴더로 이동: MVP에 필수가 아니어서 제외
- ❌ 발화 이력(여러 번의 기록)과 성장 추이: 최근 1개만 저장
- ❌ 데이터 내보내기/백업, 숙련도 기반 자동 출제·랜덤 순서: v2
- ❌ 엑셀(.xlsx) 직접 업로드: v1은 CSV만 받음

## 7. Tech Stack
- Frontend: React + Vite, JavaScript
- Backend: 없음
- Storage: localStorage (약 5MB 용량. 폴더·문장 전체를 한 키 JSON으로 저장)
- TTS/STT: 브라우저 내장 기능만 사용. 외부 서비스·유료 API 사용 안 함. Chrome 기준이며, STT의 외부 서버 사용 여부는 구현 후 확인 필요
- Hosting: v1은 로컬 실행. 배포는 v2
- 디자인: 미정. MVP는 기본 CSS로 최소한만

## 8. Success Criteria — 완성 기준
- [ ] 폴더를 만들 수 있고, 같은 이름은 거부된다
- [ ] 폴더를 삭제하면 안의 문장도 함께 사라진다
- [ ] 직접 입력으로 문장을 추가할 수 있다 (en/ko 중 하나만 채워도 됨, 둘 다 비면 거부)
- [ ] CSV를 올리면 선택한 폴더 맨 뒤에 문장이 이어 붙는다 (쉼표가 든 문장과 한글이 깨지지 않음)
- [ ] 같은 영어 문장이 이미 있어도 중복으로 추가된다
- [ ] 문장 표 화면에서 문장을 수정·삭제할 수 있고, 삭제 후 뒤 문장의 번호가 당겨진다
- [ ] 문장 표 화면과 메인 화면 모두에서 숙련도로 필터링할 수 있다
- [ ] 메인 화면의 다이얼에서 중앙 행이 완전한 형태로, 앞뒤 행이 작고 흐리게 보인다
- [ ] 중앙이 아닌 행을 클릭하면 그 행이 중앙으로 이동한다
- [ ] [듣기]를 누르면 영어 문장이 음성으로 재생된다
- [ ] 영어/한국어 열을 각각 가리고 보일 수 있고, [위로]/[아래로]로 이동해도 가리기 상태가 유지된다
- [ ] [말하기] 후 인식된 텍스트가 입력창에 나타나고, 새로고침해도 그 문장의 최근 발화가 남아 있다
- [ ] 숙련도를 바꾸고 새로고침해도 유지된다
- [ ] 필터가 켜진 상태에서 [위로]/[아래로]는 필터를 통과하는 문장 기준으로 이동한다
- [ ] 첫 문장에서 [위로], 마지막 문장에서 [아래로]를 누르면 반대쪽 끝으로 이동한다
- [ ] 문장 표 화면에는 마이크·STT·[듣기] 기능이 없다
- [ ] STT 미지원, 마이크 권한 거부, 인식 실패 때 앱이 멈추지 않고 안내가 뜬다
